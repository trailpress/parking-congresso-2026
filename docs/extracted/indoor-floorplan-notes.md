# Indoor Floorplan Notes

Note sintetiche per diorama e orientamento interno. Non inserire planimetrie reali complete, immagini dettagliate o documenti sorgente.

## Diorama interno

Obiettivo: creare una vista interna semi-3D / isometrica dell'Inalpi Arena, basata sulle planimetrie reali ma rielaborata in forma sintetica e non sensibile.

Approccio V1:

- pseudo-3D leggero;
- SVG / CSS transform / layer;
- leggibilita' prioritaria su smartphone;
- nessun 3D realistico pesante;
- nessuna planimetria reale completa pubblicata.

## Stati del diorama

1. Vista esterna: volume sintetico dell'arena, pulsante "Apri struttura", hotspot ingressi principali.
2. Exploded view: involucro esterno che si apre, visualizzazione sintetica di arena, tribune, foyer, balconate e livelli.
3. Vista per livelli: livello 0, livello +6, parterre, platea, gallerie, foyer, balconate, ingressi, aree operative.
4. Focus settore: tap su un settore -> zoom guidato sull'area.
5. Scheda hotspot: cosa e' l'area, chi deve andare li', chi la gestisce, chi contattare, eventuale percorso.

## Navigazione interna Punto A -> Punto B

La V1 puo' simulare la navigazione interna tramite nodi manuali:

- ingressi;
- scale;
- ascensori;
- corridoi;
- foyer;
- settori;
- punti di servizio.

Tipi di percorso:

- piu' rapido;
- accessibile;
- evita scale;
- preferisci ascensori;
- percorso per staff;
- percorso pubblico.

La linea del percorso deve essere mostrata sulla mappa stilizzata o sul diorama, senza esporre una planimetria reale completa.
